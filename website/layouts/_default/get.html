Install with one line (Linux and macOS)

curl -fsSL https://beetreecraft.com/install.sh | sh

The script detects your operating system and architecture, downloads the archive listed in latest.json, verifies its SHA-256 checksum, and installs beetree to ~/.local/bin. It stops without installing if the checksum does not match. Read it first at /install.sh. Set BEETREE_INSTALL_DIR to install elsewhere, or BEETREE_DRY_RUN=1 to see what it would do.

Verify a download

  1. Download the archive and SHA256SUMS into the same directory.
  2. Linux: sha256sum --ignore-missing -c SHA256SUMS. macOS: shasum -a 256 -c SHA256SUMS --ignore-missing. Windows PowerShell: Get-FileHash beetree_windows_amd64.zip and compare it to the line in SHA256SUMS.
  3. Unpack the archive, put beetree on your PATH, and run beetree version.

Then follow the CLI guide.

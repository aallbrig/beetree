A tree is just readable YAML

Write it by hand, build it in the browser, or generate it from the CLI. Every tool speaks the same format.

Read the format guide

version: "1.0"
metadata:
  name: guard
tree:
  type: selector
  name: guard_ai
  children:
    - type: sequence
      name: combat
      children:
        - {type: condition, name: can_see_target}
        - {type: action, name: chase_target}
    - {type: action, name: patrol}

The CLI, too

For pipelines and terminal people.

$ beetree validate guard.beetree.yaml
✓ guard.beetree.yaml is valid (5 nodes)

$ beetree simulate guard.beetree.yaml --override can_see_target=FAILURE
Simulation: guard_ai → SUCCESS
──────────────────────────────────────────────────
▶ ? guard_ai
  ▶ → combat
    ● ¿ can_see_target → FAILURE
  ◀ → combat → FAILURE
  ● ! patrol → SUCCESS
◀ ? guard_ai → SUCCESS

BeeTreeCraft has four ways in. They all work on the same `.beetree.yaml` format, so you can move freely between them.

| Surface | Best for | Start here |
|---|---|---|
| **Website** | Building trees visually, watching them run in 3D, sharing with others | [Website manual](/docs/manual/) |
| **CLI** | Scripts, CI pipelines, generating engine code in your repo | [CLI guide](/docs/cli/) |
| **REST API** | Integrating BeeTreeCraft into your own tools | [API docs](/docs/api/) |
| **MCP server** | Letting Claude and other AI agents work with trees | [MCP docs](/docs/mcp/) |

New to behavior trees? Read [The tree format](/docs/trees/) first. It explains the six node types in about five minutes.

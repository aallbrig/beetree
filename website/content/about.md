BeeTreeCraft is a free, open-source tool for designing, simulating and exporting engine-agnostic behavior trees for game characters. It targets Unity, Unreal and Godot.

It is created and maintained by Andrew Allbright ([aallbrig](https://github.com/aallbrig)) as an independent project. The {{< repolink >}}source{{< /repolink >}} is public, and so is the {{< repolink path="releases" >}}changelog{{< /repolink >}}: every merged change ships as a release.

BeeTreeCraft is a free, open-source tool for designing, simulating and exporting engine-agnostic behavior trees for game characters. It targets Unity, Unreal and Godot.

It is created and maintained by Andrew Allbright ([aallbrig](https://github.com/aallbrig)) as an independent project. The [source](https://github.com/aallbrig/beetreecraft) is public, and so is the [changelog](https://github.com/aallbrig/beetreecraft/releases): every merged change ships as a release.

## Get in touch

- Bugs and ideas: [open an issue](https://github.com/aallbrig/beetreecraft/issues/new)
- Questions and show-and-tell: the [forum](/app/#/forum)

Please do not post passwords, API keys or other personal details in public issues. Read the [privacy page](/privacy/) for what the site stores.
